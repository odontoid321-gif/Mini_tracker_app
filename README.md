
# Build a Task Tracker

## Project Overview

Build a Task Tracker is a menu-based Python application that allows users to manage their daily tasks. It stores tasks in a JSON file so that saved tasks can be loaded again when the program runs.

## Features

- Add new tasks.
- View all tasks with their status.
- Mark tasks as completed.
- Delete tasks.
- Save tasks in a JSON file.
- Load previously saved tasks.
- Handle empty task titles.
- Handle invalid menu choices and task numbers.
- Handle missing JSON files.

## Technologies Used

- Python
- JSON
- File Handling
- Lists and Dictionaries
- Functions
- Exception Handling

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python mini_task_tracker.py
```

5. Select an option from the menu.
6. Your tasks will automatically be saved in tasks.json.

## Menu Options

1. Add Task
2. View Tasks
3. Complete Task
4. Delete Task
5. Exit
